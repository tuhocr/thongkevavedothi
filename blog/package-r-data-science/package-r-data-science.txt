# Mở đầu

R là ngôn ngữ lập trình để xử lý dữ liệu hàng đầu hiện nay, được thiết kế chuyên để xử lý thống kê và vẽ đồ thị. Đặc điểm của R là các câu lệnh được tối ưu để tính toán theo kiểu vector, ta có thể sử dụng các function từ gói package R Base mặc định cũng như từ các package chuyên môn (bản chất là các câu lệnh R được đóng gói thành function) để tính toán nhanh gọn một tác vụ xử lý dữ liệu cụ thể.

Bạn có thể tham khảo danh sách tổng hợp các package chuyên môn theo chủ đề được nhóm phát triển R Core Team tổng hợp ở đây [CRAN Task Views](https://cran.r-project.org/web/views/).

Trong file HTML này mình tổng hợp các package và chức năng mà mình thường sử dụng khi phân tích dữ liệu nghiên cứu. Hy vọng sẽ hữu ích cho bạn để nhanh chóng áp dụng các package này vào công việc. Các bạn có thể đóng góp thêm cho danh sách được đầy đủ bằng cách chia sẻ trên [Group Cộng Đồng Tự Học R](https://www.facebook.com/groups/tuhocr) nhé. Cảm ơn các bạn rất nhiều.

Để hiểu rõ hơn cách cài đặt package trong R, bạn xem video này nhé. [Bài giảng](https://class.tuhocr.com/khoa-hoc/coding-in-r/bai-hoc/huong-dan-cach-cai-package/).

Các câu lệnh nâng cao khi xử lý package trong R. [Link](#package-function)
