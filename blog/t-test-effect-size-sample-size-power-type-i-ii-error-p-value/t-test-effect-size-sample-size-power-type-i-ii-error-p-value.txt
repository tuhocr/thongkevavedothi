# Effect size

Efect size is equivalent to minimum detectable diference in a hypothesis testing experiment. 

It is a method of quantifying the diference between the two groups’ means. 

Since diferent variables have diferent units, hence, in order to standardize, the efect size is obtained by the following formula:

$$\text{effect size} = \frac{\text{trung bình của nhóm dùng thuốc} - \text{trung bình của nhóm đối chứng}}{\text{độ lệch chuẩn}}$$

Effect size can be defned as the strength of relationship between the intervention and the variable on which its effect is investigated. 

It determines the practical signifcance of the effect in the experiments.
