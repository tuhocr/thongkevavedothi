# Định nghĩa

Phân phối Chi-squared $\chi^2$ distribution hay tiếng Việt gọi là phân phối Chi (Khi) bình phương là dạng phân phối thường gặp trong các kiểm định tỷ lệ, tần số dành cho dữ liệu count data.

Bản chất phân phối Chi-squared

$$f(x) = \frac{1}{2^{\frac{n}{2}} \Gamma(\frac{n}{2})}x^{\frac{n}{2}-1}e^{-\frac{x}{2}}$$

```{r}
v1 <- rchisq(n = 1000000, df = 1, ncp = 0)

hist(v1, 
     probability = T,
     ylim = c(0,2),
     xaxs = "i",
     yaxs = "i")
lines(density(v1))

mean(v1)
```

